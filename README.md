# remote-loader

The primary product direction is a simple Windows connectivity monitor for
machine operators. Detailed WGB and Cisco TAC diagnostics remain available as
supporting engineering layers. See the [product brief](docs/PRODUCT_BRIEF.md).

- [`roaming-script`](roaming-script/) - production Expect-based WGB diagnostics
- [`ping-script`](ping-script/) - high-frequency packet-loss monitoring
- [`wgb-diag`](wgb-diag/) - primary Windows operator application
- [`wgbtrace`](wgbtrace/) - offline engineering and TAC event-log analysis
